Information and Communication Technology Class program

The ICT Program is designed to help students understend the basic concepts of information and communication technology. Through this program, students will learn how technology is used in daily life, education, and the workplace.

Students will also develop skills in website development and database menegement. This program prepares students to think creatively, solve problems, and build simple digital projectc.

Learning Topics

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL

Learning Roadmap

  1. Learn HTML
  2. Learn CSS
  3. Learn JavaScript
  4. Learn PHP
  5. Learn MySQL

Technology Definitions

HTML
HTML is used to create the structure and content of a webpage
CSS
CSS is used to style and design the appearance of a webpage
JavaScript
JavaScript is used to make a webpage interactive and dynamic
